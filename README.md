# AriLab

**AriLab** is an interactive portfolio that showcases a collection of front-end projects, featuring various design and coding solutions from Frontend Mentor challenges. Each project is displayed as a clickable card, offering an in-depth view of the development process and finished solution.

## Features

- Responsive and interactive design
- View each project as an individual page
- Explore front-end solutions to real-world challenges
- Easy navigation between projects
